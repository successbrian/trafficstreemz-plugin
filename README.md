# TrafficStreemz Plugin for successbrian-os

A free plugin that turns a brand-new TrafficStreemz builder from zero into an
AI agentic prospecting system — installed in an afternoon, working while
you sleep.

## What this is

Most MLM "systems" are a replicated website and a prayer. This is different:
real code, running on your own machine, that finds prospects, manages
outreach, and plugs you into training — automatically.

## What you get

- **Guided setup** — contact capture, enrollments, Gmail, all wired up
- **AI prospecting engine** — finds *your* prospects (your sources, your lists)
- **Outreach automation** — Gmail + Systeme.io funnels, ready to go
- **Training built in** — the recorded presentations, on demand

## Requirements

- [successbrian-os](https://github.com/successbrian/successbrian-os)
  (this is a plugin — it needs the OS to run)
- Python 3.10+
- A fresh Gmail account (the installer walks you through it)

## Install

```bash
git clone https://github.com/successbrian/trafficstreemz-plugin
cd trafficstreemz-plugin
python3 install/onboard.py
```

See [INSTALL.md](INSTALL.md) for the full walkthrough.

## The honest deal

This plugin is free. In exchange, the installer asks for your contact
details (name, email, WhatsApp) and sends them to Brian Lathe — the builder
of this system — **so he can personally help you get it running**. That's
stated up front in the installer, not buried in fine print. Your help
setting this up *is* the product; a free AI system you can't configure
helps nobody.

The installer also offers enrollment links:
- **TrafficStreemz** — Brian is pre-filled as enroller, but you can change it.
  Your business, your choice.
- **Systeme.io** — if you don't already have it, you'll join under Brian.

## The three engines

TrafficStreemz has three income engines, and this plugin serves all three:

1. **Zilara** — wellness products, daily pay
2. **GotBackup** — cloud backup that pays for referrals
3. **My Lead Gen Secret** — daily leads, email marketing system

Each gets its own funnel, training, and prospecting profile — plus a
combined view inside the TrafficStreemz skin.

## Who this is for

**Network marketers looking for agentic AI systems.** If you've been
searching for a way to put AI agents to work in your network marketing
business — whether you're experimenting with OpenClaw, running a Hermes
agent, working with a Muse agent, or just starting to explore what AI
can do for your downline — this plugin is the on-ramp. A real agentic
AI system, open source, built specifically for network marketing.

**Zilara, GotBackup, and My Lead Gen Secret builders.** The plugin ships
with prospecting profiles for all three TrafficStreemz engines: Zilara
(Paula Scarcella's Green Organics wellness line), GotBackup (Joel
Therien's GVO cloud backup), and My Lead Gen Secret's daily lead
system. One install, three income engines — genuine multiple streams of
income from a single prospecting machine.

**Network marketers who need a real CRM.** The plugin integrates with
ContactFlowCRM, a CRM built exclusively for network marketing — not a
generic sales tool with MLM bolted on. Leads flow in scored and tagged;
follow-up runs automatically.

**Network marketers doing email outreach.** The installer wires up
Systeme.io for email automations — integrating Systeme.io with your
network marketing follow-up so sequences and nurture run without you
touching them.
