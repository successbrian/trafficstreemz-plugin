# Install Guide

## Before you start

You need [successbrian-os](https://github.com/successbrian/successbrian-os)
installed. This plugin extends it — it doesn't replace it.

## Step-by-step

### 1. Clone and launch

```bash
git clone https://github.com/successbrian/trafficstreemz-plugin
cd trafficstreemz-plugin
python3 install/onboard.py
```

### 2. Introduce yourself

The installer asks for your name, email, and WhatsApp. **Why:** Brian
personally helps every installer get this system running — he needs your
contact details to do that. This is stated on screen before you type
anything. Nothing is sent silently.

### 3. Enroll

- **TrafficStreemz** — the installer opens the enrollment page with Brian
  pre-filled as your enroller. You can change the enroller if you prefer.
- **Systeme.io** — if you don't already have an account, you'll create one
  under Brian. This powers your funnels.

### 4. Fresh Gmail

The installer walks you through creating a dedicated Gmail account for
prospecting. Keep your personal inbox clean; this one is your business
machine.

### 5. Prospecting engine

The installer configures the prospecting engine with **your** sources —
your niche, your lists, your hunting grounds. It does not come with
leads; it comes with the *machine that finds leads*.

### 6. Training

The recorded presentations (Zilara, GotBackup, My Lead Gen Secret) are
linked in the plugin. Watch them, then point your prospects at them.

## You're live

Run `python3 prospecting/finder.py --help` to see what the engine can do.
