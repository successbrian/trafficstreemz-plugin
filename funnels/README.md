# Funnels

Where the plugin meets Systeme.io and Adilo.

## Systeme.io

Each engine gets a funnel:

- `systemeio/zilara.json` — funnel template (import file)
- `systemeio/gotbackup.json` — funnel template (import file)
- `systemeio/mlgs.json` — funnel template (import file)

Templates are exported from Brian's Systeme.io account and committed
here. The installer links the user's new (or existing) Systeme.io
account; they import the template with one click.

v0.1.0: structure only. Templates land when Brian exports them.
